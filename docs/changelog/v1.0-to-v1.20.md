# Changelog: v1.0 → v1.20 (Initial Release)

**Date Range:** 2026-08-16 → 2026-08-17
**Phase:** Prototype to functional game

## v1.0 (2026-08-16) — Initial Design

**New:**
- Game concept: 1vCPU mobile 2D side-scrolling strategy
- Red Alert inspired: building-gated production
- 4 unit types: Rifleman, Rocket Soldier, Light Tank, Medium Tank
- 3 production buildings: Barracks, War Factory, Tech Center
- Vanilla HTML + Canvas2D, no build step
- Auto-placed buildings (no manual placement)
- AI: simple Markov chain

**Files:** `index.html` (~1000 lines, 3.5MB)

---

## v1.1 - v1.10 (2026-08-17) — Core Loop Polish

**Added:**
- Building queue system (max 4 queued)
- Unit queue (max 4 queued)
- Credit display
- HP bars on units and buildings
- Match-end detection (no buildings + no units = loss)
- AI: state machine (saving/defending/pushing)

**Tuning:**
- Building cost balance
- Unit HP/damage balance
- Production rate

---

## v1.11 - v1.15 (2026-08-17) — Bug Fixes + AI

**Fixed:**
- Turret attacking wrong target
- Production queue overflow
- AI not building barracks first
- Visual glitches on health bars

**Added:**
- 5 more unit types: Sniper, Flamethrower, FSV, Heavy Tank, Drone
- 2 defensive structures: Pillbox, Turret
- Main Base (500 HP)
- AI Markov + state machine combo
- Passive income (4/s)

**Tests:** 5/5 manual scenarios passing

## v1.16 - v1.20 (2026-08-17) — Visual Polish

**Fixed:**

**Files:** `index.html` (~1800 lines, 5MB)

## Lessons

- 4 days from concept to playable prototype
- AI was the hardest part — Markov alone wasn't enough
- The vanilla HTML approach was a massive win
- Building-gated production made the game 10x more interesting
