# Arcade Frontline — Event Bus Decoupling (2026-08-22)

## Impact

- Decouple game logic from Phaser rendering
- Logic emits events, render subscribes
- Replace 9 direct `scene.foo()` calls in logic
- Enable future event-sourced features (replay, network sync, etc.)
- Zero behavior change (pure refactor)

## Problem

Currently the game logic layer directly calls Phaser scene methods:

```javascript
// Layer 3 (Logic) - spawnUnit()
if (scene) scene.spawnUnitSprite(side, unitKey, spawnX, spawnY);

// Layer 4 (Render) - GameScene
spawnUnitSprite(side, unitKey, x, y) { ... }
```

**9 coupling points:**
1. `spawnUnit` → `scene.spawnUnitSprite` (line 1492)
2. `placeBuildingOnMap` → `scene.addBuildingSprite` (line 1909)
3. `placeTurretOnMap` → `scene.addTurretSprite` (line 1963)
4. `updateUnit` (5x) → `scene.fireProjectile` (lines 1671, 1691, 1711, 1736, 1759)
5. `updateTurrets` → `scene.fireProjectile` (line 1986)
6. `restartMatch` → `scene.createBaseSprites` (line 3250)

This means:
- Logic can't be unit-tested without a Phaser scene
- Adding new render layers (canvas, WebGL2, etc.) requires changing logic
- A "replay system" would have to re-run render code

## Plan

### 1. Add minimal event bus (12 lines)

```javascript
// Layer 2.5: Event Bus
const EVENTS = {};
function on(event, handler) { (EVENTS[event] = EVENTS[event] || []).push(handler); }
function emit(event, ...args) { (EVENTS[event] || []).forEach(h => h(...args)); }
function clearEvents() { for (const k in EVENTS) delete EVENTS[k]; }
```

### 2. Define event catalog

| Event | When | Payload |
|---|---|---|
| `unit:spawned` | spawnUnit() creates unit | `(side, unitKey, x, y)` |
| `building:placed` | placeBuildingOnMap | `(side, bld)` |
| `turret:placed` | placeTurretOnMap | `(side, t)` |
| `projectile:fire` | any attack | `(x, y, tx, ty, color)` |
| `match:restart` | restart button | `()` |
| `unit:died` | unit HP <= 0 | `(unit)` |
| `building:destroyed` | building HP <= 0 | `(side, bld)` |

### 3. Logic emits, Render subscribes

**Logic (Layer 3):**
```javascript
function spawnUnit(side, unitKey) {
  // ... create unit in state ...
  emit('unit:spawned', side, unitKey, spawnX, spawnY);  // ← was: scene.spawnUnitSprite
}
```

**Render (Layer 4):**
```javascript
// In GameScene.create()
on('unit:spawned', (side, unitKey, x, y) => this.spawnUnitSprite(side, unitKey, x, y));
on('projectile:fire', (x, y, tx, ty, color) => this.fireProjectile(x, y, tx, ty, color));
```

### 4. Add unit:spawned → GameScene registration

The Phaser scene's `create()` runs once at startup. The bus subscriptions need to be set up at the same time.

```javascript
// GameScene.create()
create() {
  // ... existing setup ...
  this.registerEventHandlers();
}

registerEventHandlers() {
  on('unit:spawned', (side, key, x, y) => this.spawnUnitSprite(side, key, x, y));
  on('building:placed', (side, bld) => this.addBuildingSprite(side, bld));
  on('turret:placed', (side, t) => this.addTurretSprite(side, t));
  on('projectile:fire', (x, y, tx, ty, color) => this.fireProjectile(x, y, tx, ty, color));
  on('match:restart', () => this.createBaseSprites());
}
```

### 5. clearEvents on match restart

When the match restarts, all sprites are destroyed. Need to clear event listeners too, OR use a "scene id" filter so old listeners don't fire.

Simplest: `clearEvents()` + re-register. Already need to re-init the scene on restart.

## Save Path

- Add: `EVENTS`, `on`, `emit`, `clearEvents` to Layer 2.5
- Modify: 9 logic functions to use `emit()` instead of `scene.foo()`
- Add: `registerEventHandlers()` to `GameScene`
- Add: `clearEvents()` call in `initGame()` or restart flow
- New: `docs/adr/0006-event-bus.md`
- New: `docs/architecture/event-catalog.md`

## Behavior preservation

- All 9 coupling points replaced with equivalent emit calls
- Render layer subscribes to the same events
- Net effect: zero game behavior change
- New capability: logic is now testable without Phaser
